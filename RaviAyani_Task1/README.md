 📝 Task Description
As per Oasis Infobyte Level 1 Task 1, this is a landing page project for beginners. The project demands a foundational understanding of HTML and CSS. 

Objective : To learn how to add columns, divide sections, arrange items, add headers, footers and use creativity to make the page look impressive with proper alignments, padding, color palette and boxes.

 🛠️ Tech Stack Used
- HTML5
- CSS3
- Responsive Design
- Google Fonts - Poppins

✨ Features Implemented
1. Header Section: Fixed navbar with logo and navigation links
2. Hero Section: 2-column layout with text + image
3. Services Section: 3-column layout with service cards
4. About Section: Project description
5. Footer Section: Student details and copyright
6. Responsive Design: Mobile friendly, no overlapping elements
7. Proper CSS: Used alignments, padding, margins, color palette carefully
