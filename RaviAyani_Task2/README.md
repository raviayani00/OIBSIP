## 📌 Description
A fully responsive personal portfolio website showcasing my skills, projects, and contact information. Built from scratch using HTML, CSS and JavaScript. Features smooth scrolling, modern UI design, and mobile-first approach.

## 🛠️ Tech Stack
- **HTML5** - Semantic structure
- **CSS3** - Styling, Flexbox, Grid, Animations
- **JavaScript** - Smooth scroll, Interactive elements

## ✨ Features
- Fixed navigation bar with smooth scroll
- Hero section with call-to-action button
- About Me section with skills badges
- Projects showcase with 3 project cards
- Contact section with social links
- Fully responsive design for all devices
- Clean dark blue + cyan color theme
- Hover effects and transitions
