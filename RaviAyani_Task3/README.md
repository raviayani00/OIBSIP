### Level: 1 | Task: 3
### Submitted by: Ravi Ayani

## 📌 Description
A responsive temperature converter website that converts temperature values between Celsius, Fahrenheit and Kelvin units. Built with HTML, CSS and JavaScript with real-time calculation and input validation.

## 🛠️ Tech Stack
- **HTML5** - Structure
- **CSS3** - Styling & Responsive Design
- **JavaScript** - Logic & DOM Manipulation

## ✨ Features
- Convert between Celsius, Fahrenheit and Kelvin
- Real-time conversion on input
- Input validation for empty/invalid values
- Clean and modern UI design
- Fully responsive for mobile devices
- Reset functionality
